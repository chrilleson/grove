# 1. Rust

grove is written in Rust. `grove hook` runs on every Claude Code tool call and `grove status` runs every few seconds from the tmux status line, so start-up cost matters more than anything else. A static Rust binary starts in about a millisecond, ships as one file on macOS and Linux, and Ratatui covers the TUI parts. Go was the other serious candidate (it was in the first design doc); it lost on start-up time and on the maintainer's wish to learn Rust.
