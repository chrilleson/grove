# M1 tickets

To become GitHub Issues labelled `M1` (the session that cut these had no Issues permission). Each is a vertical slice; see `docs/spec.md` for detail.

## 1. Hook handler writes task state

`grove hook <Event>` reads the Claude Code hook JSON on stdin and updates the task named by `GROVE_TASK`.

- [ ] `UserPromptSubmit`/`PreToolUse` → working; `Notification`/`PermissionRequest` → waiting; `Stop` → done + unseen; `SessionEnd` → idle; `Subagent*` never change state.
- [ ] `Stop` stores a one-line `info` from the last assistant message (payload field, else transcript).
- [ ] Raw payloads appended to `$XDG_STATE_HOME/grove/hooks.jsonl` (always during M1) so schemas can be confirmed.
- [ ] No `GROVE_TASK`, unknown task or any error → exit 0, never blocks Claude.
- [ ] No DB write when the state doesn't change (PreToolUse is hot).

## 2. `grove new` creates worktree and task session

- [ ] Repo found by name one level under configured `roots`.
- [ ] Worktree at `<root>/.worktrees/<repo>/<slug>` on new branch `<slug>` from `--base` / origin HEAD / HEAD; `worktree_root` overrides.
- [ ] Task stored with lowest free number and lowest free port block.
- [ ] tmux session `<repo>-<slug>` with `GROVE_TASK`, `GROVE_PORT` and mapped port vars; panes sidebar (32 cols) | agent | shell in the worktree; agent pane focused.
- [ ] Agent command configurable (`agent_command`, default `claude`); brief passed as first prompt.
- [ ] Switches/attaches to the new session. Refuses an existing slug.

## 3. Per-repo setup (copy, symlink, run, ports)

- [ ] Reads `~/.config/grove/repos/<repo>.toml` and the repo's `.grove.toml`; user file wins key by key.
- [ ] `setup.copy` / `setup.symlink` from the main checkout into the worktree (missing source = warning).
- [ ] `[ports]` maps names to `GROVE_PORT + offset`; set on the session and on setup commands.
- [ ] `setup.run` runs in the worktree; failure keeps the task, sets it idle with the error in `info`.
- [ ] `base` per-repo key honoured.

## 4. Sidebar pane and status-line counter

- [ ] `grove sidebar` polls the DB and lists tasks: number, icon, `repo/slug`, age, `+/−` or info line.
- [ ] Current task highlighted; done-unseen bold.
- [ ] Digits `1–9` in the sidebar switch task.
- [ ] `grove status` prints e.g. `⏳2 ✓1` (empty when nothing needs you) in <5 ms.

## 5. ⌥w rotation, ⌥1–9, seen tracking

- [ ] `grove next`: waiting first, then done-unseen, oldest first in each group, skipping the current task; message when nothing needs you.
- [ ] `grove go <n|id>`.
- [ ] `grove visit <session>` (tmux `client-session-changed`) marks a done task seen.
- [ ] A task that becomes done while you are looking at it is born seen.
- [ ] `grove ls`.

## 6. Desktop notifications on needs-you transitions

- [ ] Only on a transition *into* waiting or done-unseen.
- [ ] Never for a task a tmux client is viewing.
- [ ] `notify-send` on Linux, `osascript` on macOS; missing tool = silent. `notify = false` turns it off.

## 7. `grove init` with `--dry-run`

- [ ] Asks for roots (or `--root`), writes `config.toml` only if absent.
- [ ] Writes `grove.tmux.conf`: `M-…` binds from `[keys]`, `⌥1–9`, status counter, `client-session-changed` hook; prints the `source-file` line.
- [ ] Merges grove hook entries into `~/.claude/settings.json`, recognised by command; idempotent; user hooks untouched.
- [ ] `--dry-run` prints every change and writes nothing.
